Physician Specialty Mapping | NCO

วิเคราะห์อัตรากำลังแพทย์รายสาขา/อนุสาขา แยกจากยอดแพทย์รวม โดยใช้ข้อมูลจริงและมาตรฐานกิจกรรมที่ทวนสอบได้

ขอบเขต: เครื่องมือนี้เป็นการจัดทำข้อมูลประกอบการวางแผน ไม่ใช่กรอบอัตรากำลังที่อนุมัติแล้ว ไม่ใช้ตัวเลข CMI รวมแทนปริมาณงานแพทย์เฉพาะทาง และไม่ตีความข้อมูลที่หายไปเป็นศูนย์

1. เริ่มจากชื่อ–นามสกุลแพทย์ และตรวจสอบกับแพทยสภา

กรอกชื่อ–นามสกุล เปิดเว็บแพทยสภาเพื่อตรวจสอบ แล้วคัดลอกข้อความผลตรวจกลับมาวางหน้านี้เพื่อจับคู่สาขา ระบบยังไม่ได้เชื่อม API แพทยสภา จึงไม่ค้นหรือยืนยันแทนเว็บทางการโดยอัตโนมัติ

เปิดเว็บแพทยสภา ↗

วิธีใช้: เปิดเว็บแพทยสภา → วางชื่อ/นามสกุลคนละช่องและค้นหา → คัดลอกข้อความผลตรวจที่มีชื่อและสาขา/อนุสาขา → กลับมาวางที่นี่

รอกรอกชื่อและนำผลจากแพทยสภามาวาง

2. ระบุสาขาที่แพทย์ปฏิบัติงานจริง

แพทยสภาแสดงวุฒิ/ความเชี่ยวชาญ แต่ไม่ได้ระบุว่าแพทย์ทำงานที่โรงพยาบาลใดและใช้เวลากี่ส่วน ต้องให้ฝ่ายบุคคลยืนยัน โดยไม่เหมารวมวุฒิหลายสาขาเป็นหลายคน

    ชื่อและข้อความผลตรวจประมวลผลเฉพาะบนเบราว์เซอร์ ไม่ส่งขึ้น GitHub หรือเซิร์ฟเวอร์ หากจะสรุปอัตรากำลังขาด/เกิน ต้องมีข้อมูลภาระงานจริงและผ่านการรับรองจาก HR เพิ่มเติม

    3. นำเข้า Supply/Workload สำหรับคำนวณ FTE (ขั้นสูง)

    ใช้ไฟล์ CSV (UTF-8) ตามหัวตารางด้านล่าง ห้ามส่งชื่อ–นามสกุล, เลขบัตรประชาชน หรือข้อมูลผู้ป่วย ให้นำรหัสแพทย์ที่ทำ pseudonymization แล้วมาใช้ระบุคนเดียวกันข้ามสาขา

    กำลังโหลดบัญชีสาขาแพทย์...

    4. ผลคำนวณ FTE และ Data Fitness Gate

    Required FTE = [Σ(จำนวนงาน × นาทีต่อหน่วย) ÷ AWT] × [1 ÷ (1 − CAS%)] + (IAS ชั่วโมง × 60 ÷ AWT) โดย CAS/IAS และ Activity Standard ต้องมีหลักฐานของสาขานั้น

    5. เกณฑ์ก่อนนำเสนอผู้บริหาร

    สถานะ VERIFIED หมายถึงผ่านกติกาข้อมูลที่ตั้งไว้ในเครื่องมือนี้ ไม่ได้หมายถึงได้รับอนุมัติกรอบตำแหน่งหรือผ่านข้อกฎหมายแล้ว ต้องเทียบ HROPS, หนังสืออนุมัติ/วุฒิบัตร, การมอบหมายงานจริง, Service Plan และหลักเกณฑ์ สธ. ฉบับที่มีผลบังคับใช้ก่อนเสนอเพิ่ม/เกลี่ยตำแหน่ง

    บัญชีสาขา/อนุสาขาอ้างอิง แพทยสภา และหลักเกณฑ์กำหนดตำแหน่ง/เปลี่ยนด้านความเชี่ยวชาญควรตรวจที่ กองบริหารทรัพยากรบุคคล สธ.
